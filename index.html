How to print at the correct real-life size
  1. Choose your paper in the Paper menu at the top right, then click Print.
  2. In your browser's print dialog, match the paper size and orientation to the option you picked (for example, Letter → Landscape, or A4 → Portrait).
  3. Set Scale (sometimes labeled "Size") to 100%. Do not use "Fit to page" or "Shrink to fit" — those resize the cards.
  4. Set Margins to Default or Minimum.
  5. If your print dialog has a "Background graphics" (or "Print backgrounds") checkbox, turn it on so the full card art prints. If you don't see this option, you can ignore it.

To double-check: a printed card should measure 63 × 88 mm (about 2.5 × 3.5 in). If it's slightly off, make sure the scale is exactly 100%.
